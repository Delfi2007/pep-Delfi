## Notes

- Synthetic grooming-pattern data is non-explicit and template-based; real grooming data is PAN12 only.
- Real downloaded data (email, SMS, scans, speech, photos) contains no grooming and is used as negatives, for false-alarm testing, and to measure OCR / speech-to-text / hashing on real inputs.
- Windows Smart App Control blocked the Piper TTS library, so voice notes use the Windows built-in voices (Microsoft David / Zira at varied speaking rates).
- Known issue in this run: the first voice-note transcription silently dropped a few very short clips, which misaligned transcripts for about half of the 300 voice-note TRAINING conversations (~0.15% of all training data). The transcriber was fixed and the voice-note TEST set re-transcribed before evaluation, so voice results above are valid; retraining with corrected voice training data is a follow-up.
- RVL-CDIP scanned documents were skipped in this run (a missing parquet reader, installed too late).
- These models rank material for human review; they do not determine guilt.
